# 网络结构与源码导航

网络：S4R1_8_32_8_V1；11 卷积、13 节点、1 残差块，3808 个权重、227 个偏置，共 4035 参数。

| 节点 | 运算 | 输入节点 | 输出 H×W×C | 激活 |
|---|---|---|---|---|
| stem | conv3x3 | input | 720×1280×8 | relu |
| down_dw | dw3x3 | stem | 180×320×8 | relu |
| down_pw | pw1x1 | down_dw | 180×320×32 | relu |
| res1_a_dw | dw3x3 | down_pw | 180×320×32 | relu |
| res1_a_pw | pw1x1 | res1_a_dw | 180×320×32 | relu |
| res1_b_dw | dw3x3 | res1_a_pw | 180×320×32 | relu |
| res1_b_pw | pw1x1 | res1_b_dw | 180×320×32 | none |
| res1_add | add | res1_b_pw, down_pw | 180×320×32 | — |
| up1_low_dw | dw3x3 | res1_add | 180×320×32 | relu |
| up1_low_pw | pw1x1 | up1_low_dw | 180×320×8 | relu |
| up1_nearest | nearest | up1_low_pw | 720×1280×8 | — |
| up1_high | dw3x3 | up1_nearest | 720×1280×8 | relu |
| rgb | pw1x1 | up1_high | 720×1280×3 | none |

主路径：RGB → stem → down_dw（完整3×3、stride4）→ down_pw → 四个残差分支卷积 → res1_add（与down_pw相加）→ up1_low_dw → up1_low_pw → nearest×4 → up1_high → rgb。

所有卷积定义、groups、padding、量化和残差倍率见各 slot 的 graph.json；不同风格使用同一拓扑和各自权重。

## FPGA 对应源码

1. `network/rtl/cnn_production_frame.sv` → `cnn_frame_datapath.sv`：帧级控制和计算数据通路。
2. `fixed_video_compute.sv`、`row_pair_compute_cluster.sv`：共享执行与行对调度。
3. `fixed_production_mac.sv`、`fixed_window_dot8x32.sv`：DW/PW/3×3 乘累加与 DSP 级联。
4. `fixed_rq32_mixed.sv`、`requantize_i32_mul18_q17_pipeline.sv`：INT32 偏置、Q17 乘数、舍入与 INT8 饱和。
5. `frame_program_fetch.sv`、`frame_program_issue.sv`、`row_pair_dma.sv`：程序读取、发射和数据搬运。
6. `coefficient_bank_store_fast.sv`、`fixed_weight_loader.sv`：可变权重和各层参数装载。

## 整机连接

相机/ISP → 原图帧槽或720p缩小 → 共享CNN → 输出帧槽 → 原图/风格选择 → 中文/FPS → HDMI。Sapphire C 经 APB 请求/响应跨域桥调度相机、装载和模式；细粒度 DMA、保护和计算仍在硬件。实际整机连接见 `project/native222.v`，控制侧见 `project/rv32_control_system.sv`。

r15 在原计算核上增加模式控制网的16支组合缓冲；对应实际代码为 `project/native222.v` 的 `control_local_mode_*`，来源与逐项映射记录见 `source_binding/`。
