## 完整工程仍需队内补充

| 类别 | 当前缺项 |

## 提交仓库链接前

1. 确认使用正确版本，记录提交时的 Git commit；保留与演示镜像一致的对应关系。
2. 在一份新克隆中运行 `git lfs pull` 和完整文件校验，确认大文件能取到。
3. 核对本地正式比赛提交说明中的链接格式、报告/视频要求和评审访问方式。当前本地选题指南不足以证明必须公开仓库。
4. 私有仓库需给正式指定的评审账号访问权限。未经所有者决定，不改为公开，不向未知账号授权。
5. 如后续需要公开，先核清团队自研部分和 Efinix 受保护 IP 的可公开范围，参照[权利说明](../THIRD_PARTY_NOTICES.md)。

GitHub Actions 的“Repository integrity”只检查交付文件和文档链接，不代表 Efinity 编译或硬件测试通过。比赛表格中的“已完成”应由实际证据支持。
