# 使用说明

当前归档为 production-r15-complete（2026-11-03，11-04 入库），已提供整机工程、Sapphire/C 固件、五套模型、可读 CNN 及六槽 Flash 数据区镜像。仍没有最终 FPGA 位流或手机 APK；数据区来源标为未板验，不能据包名 complete 认定可直接整机烧录。以下硬件演示以已烧录匹配且验收通过的 r15 设备为前提。

## 准备硬件

| 组件 | 核对内容 |
| --- | --- |
| Ti60F225 开发板及 IO 板 | 与团队成功版本的板型、连接和供电一致 |
| 摄像头及排线 | 与原系统型号、接口和排线方向一致；赛题推荐 SC431HAI，当前归档未附实物型号验收记录 |
| HDMI 显示器及线缆 | 与团队本版视频输出配置一致，接板卡 HDMI 输出口 |
| 蓝牙串口链路/原手机控制端 | 使用团队已验证连接；本仓库给出 FPGA UART 侧协议，不包含 App 或蓝牙模块配置 |
| 电源与连接线 | 按板卡、屏幕及现有装配的已确认额定值使用 |

断电时检查摄像头排线、HDMI、IO 板和供电连接。外壳装配参照[装配与五金原说明](../mechanical/enclosure_v9/装配与五金说明.md)，不要凭外壳示意图猜测电气接线或端口电压。

## 已烧录设备的演示流程

1. 按团队现有接线接好摄像头、HDMI 显示器及电源，显示器选择对应 HDMI 输入。
2. 按团队已有上电流程启动，等待 C 固件完成相机配置、目录校验、数据预装和处理准备。缺少匹配 Flash 数据会使系统无法正常准备。
3. 用原设备的操作按键或蓝牙 `A5 01 FE` 触发启停事件。r15 将该事件交由 C 固件处理；未准备好时顶层会拒绝相应请求。
4. 用风格键或蓝牙 `A5 02 FD` 请求切换模式，观察漫画、阿凡达、热成像、像素动画、阴曹地府、原图六槽位 OSD。实际循环由通过校验的 Flash 目录决定；五个风格各有独立权重，第六个原图模式为 bypass。
5. 运行时用视图键或蓝牙 `A5 03 FC` 切换全/半屏；顶层对该按键有运行及就绪条件。以实际屏幕名称和画面记录各模式，不混用旧五模式版的操作截图。
6. 记录本版 AI FPS、输入/输出配置和切换表现，保留与 commit/镜像对应的视频。HDMI 为源码配置的 1080p30，风格模型为 720p；显示可重复最近一帧，不能把 30Hz 当成 AI 吞吐。旧版约 17.1 FPS 不作为 r15 实测。

本版已附引脚和外设配置。实体按键位置应结合 `fpga/project/outflow/` 中 pinout、外设 XML 和原板标签核对，不凭内部事件名猜测 SW 编号。

蓝牙命令必须按原始十六进制字节发送，一次连续发送完整三字节，不要发 ASCII 字符串或附加回车换行。详细时序见[协议说明](ble-protocol.md)。UART TX 当前空闲为高，没有命令确认回包。

## 从代码开始

先运行[完整性检查](verification.md)，再阅读[原包说明](../fpga/README.md)和[工程使用说明](fpga-project.md)。用 Efinity 2026.1.132 打开 `fpga/project/ti60f225_oob.xml`；修改 C 固件时使用 RV32 GCC 15.2.0。`firmware/prebuilt/control.bin` 是 CPU 固件，不能作为 FPGA 下载位流。

仅在电脑上比较图片效果可直接用[网络与模型](network.md)的包内推理入口，输入需为 1280×720 RGB，无需连接板卡。Flash 数据区 `network/runtime_data/flash-user-data.bin` 从 `0x340000` 起，绝不能当整片镜像从 0 写入；还需核对匹配位流、相机更新及回读验收。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 大网表或 STL 只有几行 | 是否拿到 LFS 指针；在仓库内运行 `git lfs pull` 后重做校验 |
| Efinity 工程加载或编译失败 | 是否打开本版 XML、使用同版工具和器件支持、保留完整 project/outflow/ROM；本次未验证综合结果 |
| 屏幕无信号 | 已验证镜像、供电、HDMI 输出端、线缆及显示模式 |
| 上电无法准备、画面不更新 | r15 的相机诊断、目录/CRC、生产 Flash 数据、fault/run_state、启动事件及模式；保留故障记录 |
| 蓝牙命令无反应 | 模块已连接、UART 接线与配置、115200/8N1、原始三字节及命令间隔；不要等待并不存在的 ACK |
| 风格名称暂时未更新 | 名称在帧开始锁存，并受处理就绪信号控制，不能据此独立判断整条链路故障 |
| 外壳试装干涉 | 核对 V9-P1、mm/100% 缩放、打印收缩、试配环和实际线缆/插头尺寸 |

复现故障时请记录版本和具体操作，不要先覆盖板上已验证镜像或用未知工程重烧。
