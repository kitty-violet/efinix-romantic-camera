# 赛题要求与本版本对照

核对日期：2026-11-03。当前代码：production-r15。此前“无 RISC-V、仅四个 HDL”的描述只适用于历史提交 `423d07a`，不再用于本版本。

依据团队已有《全国大学生嵌入式芯片与系统设计竞赛'2026 FPGA 创新设计赛道选题指南（易灵思）》共 21 页，平台说明见 PDF 第 3-4 页，赛题一“AI 赋能的「实时绘画」——风格化视频渲染系统”见 PDF 第 4-7 页。本次没有把厂家/组委会整份 PDF 复制到仓库，也没有用未经确认的网络规则替代本地版本。

“原说明记录”表示 r15 包中的声明；“源码可见”只表示本次阅读能确认的实现；“未提供”表示此仓库缺少材料或实测证据。本次执行原包校验、工程引用和 ROM 一致性检查，没有运行综合、仿真或实板测试。

| 总线访问 DDR 完成推理读写 | 已附 `control.h`、服务后端、DMA 和 C 调度 | 完整总线/地址图、带宽及端到端推理验证 |

## 高阶挑战

| 赛题条目 | 当前仓库情况 | 需要补充 |
| --- | --- | --- |
| 至少两套网络权重，动态切换，不重配 FPGA | 六显示槽位，C 支持校验目录、预装驻留槽、切换系数和任务；未附生产权重/目录镜像 | 各模式与网络映射、生产数据及实际切换证据 |
| 切换延迟低于 100ms，切换不丢帧 | C 先排空再准备/恢复，原包称 r15 使用 16 支模式控制缓冲；无延迟实测 | 同步触发与输出的测量记录 |
| 1280×720@30fps 或更高处理吞吐 | 没有本版测量结果，不能据逻辑时钟或 HDMI 时序宣称 AI 吞吐 | r15 吞吐、延迟与稳定性数据 |
| 小于 500KB 网络、结构图、参数量表 | 未提供 | 网络结构、精度、参数/权重统计 |
| 对照标准网络的 PSNR/SSIM、推理延迟 | 未提供 | 数据集、评估脚本、指标和对比口径 |
| 创意交互及附加展示视频 | 有 BLE/按键事件、中文 OSD 和全半屏控制源码；无 APK/视频 | 手机控制演示、协议/应用版本及运行录像 |

r15 已有 RISC-V 与工程配置，上一版相应缺项已解除；源码齐备和引用正确仍不能替代构建/性能验收。V9 外壳资料继续原样保留，其历史数值检查不等同于实物打印验收。
