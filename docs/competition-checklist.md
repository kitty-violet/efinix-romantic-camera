# 赛题要求与本版本对照

核对日期：2026-11-04。当前归档：production-r15-complete（原包日期 2026-11-03）。此前“无 RISC-V、仅四个 HDL”的描述只适用于历史提交 `423d07a`，不再用于本版本。

依据团队已有《全国大学生嵌入式芯片与系统设计竞赛'2026 FPGA 创新设计赛道选题指南（易灵思）》共 21 页，平台说明见 PDF 第 3-4 页，赛题一“AI 赋能的「实时绘画」——风格化视频渲染系统”见 PDF 第 4-7 页。本次没有把厂家/组委会整份 PDF 复制到仓库，也没有用未经确认的网络规则替代本地版本。

“原说明记录”表示来源包中的声明；“源码可见”只表示阅读能确认的实现；“未提供”表示缺少材料或实测证据。本轮重新执行文件、工程引用、ROM、整数参数/参考向量、描述符及运行数据内存重建校验，没有执行训练、综合、HDL 仿真或实板测试。包内 PyTorch 和 Questa 检查结果是来源记录。

## 高阶挑战

| 赛题条目 | 当前仓库情况 | 需要补充 |
| --- | --- | --- |
| 至少两套网络权重，动态切换，不重配 FPGA | 五套独立 checkpoint/整数权重及六槽目录已附，C 支持驻留与切换；第六槽为原图 bypass，不是独立 CNN | 匹配位流和数据区、实际动态切换验收 |
| 切换延迟低于 100ms，切换不丢帧 | C 先排空再准备/恢复，原包称 r15 使用 16 支模式控制缓冲；无延迟实测 | 同步触发与输出的测量记录 |
| 1280×720@30fps 或更高处理吞吐 | 没有本版测量结果，不能据逻辑时钟或 HDMI 时序宣称 AI 吞吐 | r15 吞吐、延迟与稳定性数据 |
| 小于 500KB 网络、结构图、参数量表 | 已附逐层结构/连接表和参数表；每风格 4035 参数，checkpoint 28,519B，整数系数 5708B，驻留布局 20,480B | 注明统计是否含量化元数据/调度程序，补正式报告图及精度证据；程序大小不混作网络权重 |
| 对照标准网络的 PSNR/SSIM、推理延迟 | 未提供 | 数据集、评估脚本、指标和对比口径 |
| 创意交互及附加展示视频 | 有 BLE/按键事件、中文 OSD 和全半屏控制源码；无 APK/视频 | 手机控制演示、协议/应用版本及运行录像 |

r15 已有 RISC-V、工程配置、模型/可读核和运行数据，相应材料缺项已解除；数据区来源仍标记未板验，且没有最终位流。源码齐备和引用正确不能替代构建/性能验收。V9 外壳继续原样保留，其历史数值检查不等同于实物打印验收。
