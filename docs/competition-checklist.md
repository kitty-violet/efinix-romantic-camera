# 赛题要求与本版本对照

核对日期：2026-11-02。

依据团队已有《全国大学生嵌入式芯片与系统设计竞赛'2026 FPGA 创新设计赛道选题指南（易灵思）》共 21 页，平台说明见 PDF 第 3-4 页，赛题一“AI 赋能的「实时绘画」——风格化视频渲染系统”见 PDF 第 4-7 页。本次没有把厂家/组委会整份 PDF 复制到仓库，也没有用未经确认的网络规则替代本地版本。

“原说明记录”表示团队交付包中的文字声明；“源码可见”只表示本次阅读文件能确认的事实；“未提供”表示这个仓库缺少相应材料或证据，不能据此认定原设备没有该功能。

## 基础要求

| 赛题条目 | 当前仓库情况 | 提交/复现所需材料 |
| --- | --- | --- |
| Ti60F225 平台 | 原说明记录 Ti60F225；顶层为 `ti60f225_oob_top` | 实际板型、完整料号、接线与配置记录 |
| MIPI CSI-2、SC431HAI、RAW 转 RGB/Resize，至少 640×480@30fps | 原说明记录 1280×720 图像处理；本次未验证采集速率与传感器型号 | 相机配置、接口配置、输入时序及实测记录 |
| DDR Ping-Pong 不丢帧 | 冻结网表归档，未附缓存机制设计说明或流量测试 | 缓冲/所有权设计、DDR 配置、丢帧测试 |
| 3×3/5×5 卷积、激活、BN/IN 近似硬件 | 未附可维护加速器源、网络结构或算子对照 | 算子实现说明、量化参数、仿真和综合证据 |
| 总线访问 DDR 完成推理读写 | 未附总线架构、寄存器及带宽报告 | 总线/地址图、调度与带宽验证 |
| HDMI 至少 720p60 或 1080p30 | 原说明记录 1920×1080@30Hz 输出 | HDMI 实测视频、时序及稳定性记录 |
| RISC-V C 驱动完成相机初始化、权重加载、任务调度/中断 | **原说明明确此冻结版本无 RISC-V，未满足此结构性要求** | 若按赛题一提交，应补充对应实现，或向组委会核实当前方案的参赛适用性 |
| 原图/风格图对比或按键切换 | 原说明记录视图控制；源码可见 `key_view` 事件 | 实际视图布局、操作和对比录像 |
| 实时 FPS，640×480 稳定 15fps 以上 | 原说明记录 AI 约 17.1 FPS，未附本次测量日志；不能直接当作指定条件的独立验收 | 明确测量分辨率、窗口和计数口径的证据 |

## 高阶挑战

| 赛题条目 | 当前仓库情况 | 需要补充 |
| --- | --- | --- |
| 至少两套网络权重，动态切换，不重配 FPGA | 有五种视觉模式名称，未提供独立权重/网络文件 | 每种模式与网络/权重的映射、权重清单及加载方式 |
| 切换延迟低于 100ms，切换不丢帧 | 未附延迟和丢帧测试 | 同步触发与输出的测量记录 |
| 1280×720@30fps 或更高处理吞吐 | 记录 1280×720、约 17.1 AI FPS，**不能宣称达到 720p30 AI 处理** | 优化后的吞吐/延迟与稳定性数据 |
| 小于 500KB 网络、结构图、参数量表 | 未提供 | 网络结构、精度、参数/权重统计 |
| 对照标准网络的 PSNR/SSIM、推理延迟 | 未提供 | 数据集、评估脚本、指标和对比口径 |
| 创意交互及附加展示视频 | 原说明称手机三项控制已验证，源码有对应 UART 命令；无 APK/视频 | 手机控制演示、协议/应用版本及运行录像 |

V9 外壳属于作品集成资料，不替代赛题对硬件加速器、RISC-V 和性能的要求。它的 CAD/网格历史检查也不等同于实物打印验收。

## GitHub 与评审访问

本次阅读的本地易灵思选题指南和总赛题指南中未找到“必须公开 GitHub 仓库”的明确条款。按团队要求建立私有 GitHub 仓库作为代码和机械资料交付入口；具体比赛平台的仓库链接字段、公开性、评委账号与额外文件要求，以团队收到的正式提交说明为准。

私有仓库不能被未授权评委直接访问。提交前应由仓库所有者按正式安排授予访问，或在确认可公开范围后决定是否改为公开。本次归档不会自动邀请协作者或修改公开性。
